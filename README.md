# Fashion MNIST ANN Pipeline

This project builds a reproducible, fully connected artificial neural network for classifying Fashion-MNIST images into 10 clothing categories.

The workflow will use:

- TensorFlow for model training and evaluation
- Git for source-code versioning
- DVC for data, model, metric, and pipeline versioning
- Google Drive as the DVC remote storage

The target is at least 85% test accuracy. The completed pipeline will contain separate prepare, preprocess, train, and evaluate stages and will be reproducible with a single DVC pipeline run.
